1. Verdict (Ringkasan Eksekutif)

  • Karakteristik Sistem: Aplikasi helpdesk internal. Tidak ditujukan untuk perolehan traffic organik publik dari mesin pencari.
  • Celah Kritis #1: public/robots.txt saat ini bernilai Disallow: kosong, memperbolehkan Googlebot, Bingbot, dan AI scraper merayapi seluruh endpoint sistem.
  • Celah Kritis #2: Rute utilitas /system/clear dan /system/optimize pada routes/web.php dapat diakses publik tanpa login. Jika bot perayap mengeksekusi URL ini, cache sistem terhapus terus-menerus dan membebani resource server.
  • Celah Kritis #3: Halaman TV Dashboard di /tv menampilkan data tiket dan antrean publik tanpa tag noindex, sehingga berpotensi terindeks ke hasil pencarian.

2. Top Priority (Aksi Utama Minggu Ini)

Langkah 1: Perbarui public/robots.txt

Kunci perayapan bot ke seluruh rute privat, API, dan utilitas:

User-agent: *
Disallow: /admin/
Disallow: /dashboard
Disallow: /tiket/
Disallow: /chat/
Disallow: /tv
Disallow: /system/
Disallow: /api/
Disallow: /lupa-password
Disallow: /reset-password/

Allow: /login$
Allow: /favicon.ico
Allow: /images/

User-agent: GPTBot
Disallow: /

User-agent: CCBot
Disallow: /

Langkah 2: Amankan Rute Cache di routes/web.php

Bungkus endpoint /system/optimize dan /system/clear dengan middleware auth dan role:admin:

Route::middleware(['auth', 'role:admin'])->prefix('system')->group(function () {
    Route::get('/optimize', function() {
        \Illuminate\Support\Facades\Artisan::call('config:cache');
        \Illuminate\Support\Facades\Artisan::call('route:cache');
        \Illuminate\Support\Facades\Artisan::call('view:cache');
        return 'System optimized.';
    });

    Route::get('/clear', function() {
        \Illuminate\Support\Facades\Artisan::call('config:clear');
        \Illuminate\Support\Facades\Artisan::call('route:clear');
        \Illuminate\Support\Facades\Artisan::call('view:clear');
        \Illuminate\Support\Facades\Artisan::call('cache:clear');
        return 'System cache cleared.';
    });
});

Langkah 3: Tambahkan Header HTTP X-Robots-Tag

Pada app/Http/Middleware/SecurityHeaders.php, tambahkan baris berikut agar seluruh response membawa instruksi noindex:

$response->headers->set('X-Robots-Tag', 'noindex, nofollow, noarchive');

3. Small Fixes (Perbaikan Teknis)

1. Meta Description & Meta Robots di resources/views/app.blade.php Tinggi

Tambahkan tag meta dasar di dalam <head>:

<meta name="robots" content="noindex, nofollow">
<meta name="description" content="Sistem Layanan Helpdesk Internal Halo APU. Layanan pelaporan dan monitoring tiket.">
2. Pasang Link Canonical Dinamis Sedang

Mencegah duplikasi URL antara subdomain dan port:

<link rel="canonical" href="{{ url()->current() }}">
3. Open Graph Tags untuk Link Preview Chat Internal Sedang

Agar saat tautan login dibagikan di WhatsApp/Teams, kartu preview tampil rapi:

<meta property="og:type" content="website">
<meta property="og:title" content="{{ config('app.name', 'Halo APU') }}">
<meta property="og:description" content="Portal Helpdesk Internal Halo APU">
<meta property="og:image" content="{{ asset('images/logo.png') }}">
<meta property="og:url" content="{{ url()->current() }}">
4. Preconnect Google Fonts Rendah

Mempercepat handshake TLS saat merender font eksternal:

<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>

4. What's Working Now (Kondisi Bagus Saat Ini)

  • Security Headers Lengkap: X-Frame-Options: DENY, X-Content-Type-Options: nosniff, HSTS, dan CSP sudah aktif via middleware.
  • Vite Asset Bundling: Hashing aset otomatis untuk cache busting instan.
  • Pencegahan Direktori Browsing: Options -Indexes aktif di .htaccess.
  • 301 Redirect Trailing Slash: Normalisasi URL trailing slash berjalan dengan baik.

5. Roadmap Tindakan

  1. Hari 1: Terapkan perbaikan robots.txt dan amankan rute /system/*.
  2. Hari 2: Tambahkan X-Robots-Tag di SecurityHeaders.php.
  3. Hari 3: Lengkapi meta tags dan link canonical di resources/views/app.blade.php.
