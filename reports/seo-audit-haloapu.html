Halo APU merupakan aplikasi helpdesk internal terintegrasi berbasis Laravel 13 dan Inertia.js React. Audit ini berfokus pada Technical SEO, keamanan perayapan (crawl safety), serta pencegahan kebocoran indeks data sensitif ke mesin pencari publik (Google, Bing, Yahoo).

Security Headers (CSP/HSTS)
  • Karakteristik Domain: Sistem helpdesk internal operasional (bukan portal konten publik). Sasaran SEO adalah zero-leakage indexing pada area operasional dan metadata bersih pada gerbang login publik.
  • Celah Kritis #1: File public/robots.txt mengizinkan seluruh bot merayapi seluruh direktori (User-agent: * Disallow:). Bot perayap publik diizinkan merayapi endpoint apa pun.
  • Celah Kritis #2: Rute utilitas /system/clear dan /system/optimize pada routes/web.php bersifat publik tanpa autentikasi. Jika crawler atau scraper mengunjungi URL ini, cache aplikasi terhapus secara otomatis dan memicu lonjakan beban CPU/I/O server.
  • Celah Kritis #3: Halaman TV operasional /tv bersifat publik dan menampilkan nomor tiket serta status pekerjaan langsung tanpa tag noindex, berpotensi masuk ke indeks pencarian Google.
  • Kelengkapan Metadata: Template resources/views/app.blade.php belum memiliki meta description, Open Graph preview, dan canonical tag.

2. Top Priority (Aksi Utama Minggu Ini)

Satu tindakan paling penting minggu ini adalah menutup celah perayapan bot publik pada rute sistem dan menerapkan kebijakan noindex ketat.

Langkah 1: Perbarui public/robots.txt

  • Status Saat Ini: File hanya berisi User-agent: * \n Disallow: yang berarti mengizinkan semua bot merayapi semua rute.
  • Solusi: Ganti isi public/robots.txt dengan aturan pemblokiran perayap untuk semua halaman sistem, admin, API, dan dashboard TV:
# robots.txt untuk Halo APU (dev.haloapu.id)
User-agent: *
# Larang perayapan seluruh area aplikasi privat dan utilitas
Disallow: /admin/
Disallow: /dashboard
Disallow: /tiket/
Disallow: /chat/
Disallow: /tv
Disallow: /system/
Disallow: /api/
Disallow: /lupa-password
Disallow: /reset-password/

# Izinkan hanya landing page login jika ingin terdeteksi oleh nama brand
Allow: /login$
Allow: /favicon.ico
Allow: /images/

# Larang pengindeksan AI crawler dan scraper data
User-agent: GPTBot
Disallow: /

User-agent: CCBot
Disallow: /

User-agent: Google-Extended
Disallow: /

Langkah 2: Amankan Endpoint Utilitas di routes/web.php

  • Status Saat Ini: /system/optimize dan /system/clear dapat dieksekusi siapa saja dengan metode GET tanpa proteksi token atau auth.
  • Solusi: Pindahkan kedua rute ini ke dalam grup middleware auth dan role:admin, atau hapus rute web ini dan jalankan perintah optimasi murni melalui CLI (Artisan).
// Pindahkan ke dalam middleware auth dan admin
Route::middleware(['auth', 'role:admin'])->prefix('system')->group(function () {
    Route::get('/optimize', function() {
        \Illuminate\Support\Facades\Artisan::call('config:cache');
        \Illuminate\Support\Facades\Artisan::call('route:cache');
        \Illuminate\Support\Facades\Artisan::call('view:cache');
        return 'System optimized successfully.';
    });

    Route::get('/clear', function() {
        \Illuminate\Support\Facades\Artisan::call('config:clear');
        \Illuminate\Support\Facades\Artisan::call('route:clear');
        \Illuminate\Support\Facades\Artisan::call('view:clear');
        \Illuminate\Support\Facades\Artisan::call('cache:clear');
        return 'System cache cleared successfully.';
    });
});

Langkah 3: Tambahkan Header HTTP X-Robots-Tag

  • Status: File app/Http/Middleware/SecurityHeaders.php sudah ada dan berjalan di setiap response HTTP.
  • Solusi: Tambahkan instruksi X-Robots-Tag: noindex, nofollow, noarchive di dalam middleware ini untuk memastikan seluruh halaman dinamis tidak disimpan dalam cache mesin pencari:
// Tambahkan di dalam app/Http/Middleware/SecurityHeaders.php pada handle():
$response->headers->set('X-Robots-Tag', 'noindex, nofollow, noarchive');

Catatan Istilah: X-Robots-Tag adalah instruksi HTTP header kepada crawler mesin pencari (seperti Googlebot) yang berfungsi sama seperti tag HTML meta robots, namun berlaku efektif untuk seluruh tipe file (HTML, API JSON, PDF, dan lampiran file).

3. Small Fixes (Perbaikan Teknis Pendukung)

1. Tambahkan Meta Robots dan Meta Description di resources/views/app.blade.php

  • Status: Tag <head> hanya memuat charset, viewport, dan title. Tidak ada deskripsi dan meta indexing.
  • Perbaikan: Tambahkan tag meta standar pada template utama:
<meta name="robots" content="noindex, nofollow">
<meta name="description" content="Sistem Layanan Helpdesk Internal Halo APU. Akses terproteksi untuk pelaporan tiket dan pemantauan operasional.">

2. Pasang Tag Canonical Dinamis

  • Status: Tidak ada tag <link rel="canonical">.
  • Perbaikan: Pasang link canonical dinamis pada app.blade.php agar crawler memahami URL acuan resmi:
<link rel="canonical" href="{{ url()->current() }}">

3. Pasang Open Graph (OG) Meta Tags untuk Internal Share Preview

  • Status: Ketika tautan portal helpdesk dibagikan di WhatsApp, Telegram, atau Slack tim, tidak muncul preview visual (thumbnail/deskripsi) yang profesional.
  • Perbaikan: Tambahkan Open Graph dasar pada app.blade.php:
<meta property="og:type" content="website">
<meta property="og:title" content="{{ config('app.name', 'Halo APU') }} - Helpdesk System">
<meta property="og:description" content="Layanan bantuan tiket dan monitoring operasional internal Halo APU.">
<meta property="og:image" content="{{ asset('images/logo.png') }}">
<meta property="og:url" content="{{ url()->current() }}">

4. Tambahkan Preconnect untuk Web Fonts

  • Status: CSP mengizinkan Google Fonts (fonts.googleapis.com dan fonts.gstatic.com), namun belum ada preconnect di <head>.
  • Perbaikan: Tambahkan baris preconnect untuk mempercepat proses TLS handshake font saat halaman login dimuat:
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>

5. Perbaiki Hierarki Semantik Heading H1 di Layar Login

  • Status: Pada resources/js/Pages/Auth/UserLogin.tsx dan AdminLogin.tsx, judul form login menggunakan elemen teks biasa tanpa tag semantik <h1>.
  • Perbaikan: Gunakan tag <h1> untuk judul "Login ke Halo APU" guna memenuhi standar aksesibilitas dan struktur dokumen HTML yang valid.

4. What's Working Now (Aspek yang Sudah Bagus)

  • Security Headers Komprehensif: Middleware SecurityHeaders.php sudah mengimplementasikan X-Frame-Options: DENY, X-Content-Type-Options: nosniff, HSTS (Strict-Transport-Security), dan Content Security Policy (CSP). Ini adalah nilai tambah besar untuk keamanan web.
  • Asset Bundling Modern (Vite): Aset JavaScript dan CSS di-bundle dengan hashing unik (misal: app-BQGaRtfq.js), mendukung cache-busting instan saat rilis kode baru.
  • Pencegahan Directory Browsing: File public/.htaccess mengaktifkan Options -Indexes, mencegah pengunjung melihat daftar isi folder server.
  • Canonical Trailing Slash: File .htaccess secara otomatis melakukan redirect 301 untuk URL dengan trailing slash (menghilangkan potensi duplikasi URL).
  • Viewport Standar Mobile: Pengaturan viewport pada app.blade.php sudah responsif dan ramah perangkat seluler.

5. What to Do Next (Rencana Tindakan Berurutan)

  1. Hari ke-1 (Prioritas Tertinggi): Update public/robots.txt dengan aturan pembatasan di atas dan pindahkan rute /system/clear & /system/optimize ke dalam otentikasi admin.
  2. Hari ke-2: Tambahkan header X-Robots-Tag: noindex, nofollow, noarchive ke dalam app/Http/Middleware/SecurityHeaders.php.
  3. Hari ke-3: Perbarui resources/views/app.blade.php dengan meta description, tag canonical, dan Open Graph preview.
  4. Hari ke-4: Pasang tag semantik <h1> pada komponen form autentikasi di frontend.
